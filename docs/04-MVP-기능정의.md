# 04. MVP 기능 정의

> 작성일: 2026-07-20
> 원칙: MVP는 **"용기 → 연락 → 기록"** 루프 하나를 완성한다. 용서 프로그램(REACH)은 MVP+1, B2B는 그 이후.

## MVP 범위 한눈에

| 단계 | 포함 | 제외 (이후 버전) |
|---|---|---|
| MVP | 관계 등록, 추억 기록(카테고리), 재연락 미션(워밍업→본연락), 메시지 초안 도우미, 리마인더, 결과 기록 | REACH 용서 프로그램, 사과 코스, 관계망 시각화, AI 코칭 고도화, B2B |

---

## 1. 관계 등록 (사람 잇기)

- 사람 추가: 직접 입력 or **연락처에서 선택적으로 불러오기** (전체 동기화 없음 — iOS ContactAccessButton/선택 피커, [00-리서치보고서](00-리서치보고서.md) §3)
- 관계 유형: `가족(부모/형제/자녀/친척)` `친구` `연인/전배우자` `은사/제자` `직장동료` `기타`
- 관계 상태 (핵심 축):
  - 🔵 **이어진 관계** — 잘 지내는 중 (유지 리마인더 대상)
  - 🟡 **멀어진 관계** — 갈등은 없지만 오래 연락 못 함 (재연락 미션 대상)
  - 🔴 **틀어진 관계** — 갈등/오해로 단절 (회복 프로그램 대상, MVP+1)
- 등록 시 안전 스크리닝 1문항: "이 관계에서 위협·폭력을 경험한 적이 있나요?" → 예 → 재연결 유도 기능 차단 + 전문기관 안내 ([01-아이디어](01-아이디어.md) 윤리 원칙)

## 2. 추억 기록 (마음 잇기)

입력 마찰을 최소화하기 위해 **전부 선택형 → 마지막에만 자유 텍스트**.

- 추억 카테고리 (탭 한 번):
  `함께한 여행` `학창 시절` `같이 먹던 것` `함께 웃었던 일` `힘들 때 도와준 일` `함께 이룬 것` `사소한 일상` `선물` `직접 입력`
- 감정 태그: `그리움` `고마움` `미안함` `즐거움` `아쉬움`
- 시기: 연도 슬라이더 (정확한 날짜 강요 안 함)
- 사진 첨부 (선택)
- 한 줄 메모 (선택)
- **활용**: 추억은 ① 재연락 메시지의 소재("그때 같이 갔던 부산 기억나?")로 자동 제안되고 ② 관계 카드의 자산으로 쌓인다

## 3. 재연락 미션 (용기 잇기) — 잇다의 심장

연구 근거를 그대로 제품화한 3단계 플로우 (31%→53% 개입, [00-리서치보고서](00-리서치보고서.md) §1-1):

### 3-1. 워밍업 (3분)
- "먼저 가까운 사람에게 가벼운 안부를 보내보세요" — 현재 편한 친구 1명에게 짧은 메시지 보내기 미션
- 완료 체크만 하면 됨 (메시지는 카톡/문자로)

### 3-2. 용기 부스터
본 연락 직전 화면에서 근거 기반 넛지 제시:
- "연구에 따르면, 연락받은 사람은 보낸 사람의 예상보다 훨씬 반가워했어요 (JPSP, 5,900명 실험)"
- "오랜 친구에게 연락하는 게 낯선 사람에게 말 거는 것만큼 떨리는 건 정상이에요. 상대도 똑같이 못 하고 있을 뿐이에요"
- 등록해둔 추억 카드 1장을 보여줌 ("이 추억을 기억하는 사람은 세상에 두 명뿐이에요")

### 3-3. 메시지 초안 도우미
- 템플릿 3종: `가벼운 안부형` `추억 소환형` `솔직 고백형("연락 못 해서 미안, 계속 생각났어")`
- 추억 데이터를 템플릿에 자동 삽입
- (선택) AI 다듬기 — Claude API로 톤 조정. 서버 경유, 저장 안 함
- **[보내기] 버튼은 없다.** [복사하고 카톡 열기]만 있다 — 보내는 행위는 항상 사용자의 것

### 3-4. 결과 기록
- 24시간 후 푸시: "어떻게 됐나요?" → `답장 왔어요 😊` `아직 답 없어요` `못 보냈어요`
- "답장 왔어요" = North Star 지표 카운트
- "못 보냈어요" → 부담 없는 격려 + 다음 워밍업 제안 (죄책감 유발 금지)

## 4. 리마인더 (잇기 유지)

- 관계별 연락 주기 설정 (월 1회 등) → 푸시
- 기념일(생일 등) 등록 시 D-day 알림
- 시즌 캠페인 훅: 설·추석·연말 "올해가 가기 전에 잇고 싶은 사람" (마케팅 연계)

## 5. 홈 화면 구성

- 상단: "다시 잇고 싶은 사람" 카드 (멀어진 관계 중 1명 추천 — 등록 후 오래 방치된 순)
- 중단: 진행 중인 미션 상태
- 하단: 내 사람들 리스트 (상태별 필터)

## MVP+1 (다음 버전 예고)

- **용서 여정**: REACH 5단계 셀프 프로그램 (하루 10분 × 4주, 저널링 기반) — 🔴 틀어진 관계 대상
- **사과 작성 코스**: 6요소 블록 에디터 (책임 인정·보상 제안 필수 블록, 변명 감지 경고)
- **화해 초대**: 상대에게 잇다 링크로 "대화 요청장" 보내기 (Paired식 — 받는 쪽은 무료)
- 관계망 시각화 (내 사람들 지도)
