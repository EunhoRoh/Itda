# 11. 테스트 시나리오 (수동 QA)

> 대상: MVP 핵심 루프 + 안전/리마인더. 환경별 실행 가능 여부를 먼저 표기한다.
> 실행 전 서버: backend `http://localhost:8090`, expo-web `http://localhost:8082`, 폰은 Expo Go(`npx expo start --port 8082` QR).

## 환경별 커버리지

| 기능 영역 | 웹 미리보기 | 실기기(Expo Go) |
|---|---|---|
| 홈 추천/카운트/미션 카드 | ✅ | ✅ |
| 사람 등록 4스텝 + 안전 스크리닝 | ✅ | ✅ |
| 추억 기록 | ✅ | ✅ |
| 재연락 미션 4단계 | ✅ | ✅ |
| 관계 상세 + 상태 전환 | ✅ | ✅ |
| **연락처에서 고르기** | ❌ (버튼 숨김) | ✅ |
| **리마인더/24h 알림 실제 울림** | ❌ (no-op) | ✅ |
| 초안 "카카오톡 열기" 딥링크 | ⚠️ 복사만 | ✅ |

## TC-01 홈 · 오늘의 한 사람
| # | 단계 | 기대 결과 |
|---|---|---|
| 01-1 | 홈 진입 | 오늘 날짜, "오늘 한 사람만 이어볼까요?" 헤드라인 노출 |
| 01-2 | 히어로 카드 확인 | 멀어진 관계 중 **가장 오래 연락 끊긴 1명** + 추억 1줄 표시 |
| 01-3 | 하단 카운트 | 이어진/멀어진/틀어진 수가 실제 등록 데이터와 일치 |
| 01-4 | "다음에 할게요" 탭 | 다음 후보로 카드 교체 (후보 2명 이상일 때만 노출) |
| 01-5 | 진행 중 미션 있을 때 | 미션 카드 표시, 탭 시 해당 미션으로 이동 |

## TC-02 사람 등록 (4스텝)
| # | 단계 | 기대 결과 |
|---|---|---|
| 02-1 | 사람들 탭 → "+ 사람 잇기" | 등록 모달, 1/4 "누구를 이어볼까요?" |
| 02-2 | 이름 없이 다음 | 버튼 비활성(진행 불가) |
| 02-3 | 이름 입력 → 다음 | 2/4 관계 유형 선택 화면 |
| 02-4 | 관계 유형 선택 → 다음 | 3/4 상태 3택(🔵🟡🔴) |
| 02-5 | 상태 선택 → 다음 | 4/4 안전 확인 |
| 02-6 | "아니요" → 이어두기 | 목록에 추가, reconnectAllowed=true |
| 02-7 | **"네, 있었어요" 선택** | 즉시 보호 안내(1366) 배너 노출 |
| 02-8 | 02-7 상태로 저장 | 저장됨, 상세에서 **보호 모드**로 표시 |
| 02-9 | 뒤로가기(← 이전) | 스텝 되돌아감, 입력값 유지 |

## TC-03 추억 기록
| # | 단계 | 기대 결과 |
|---|---|---|
| 03-1 | 사람 카드 "+ 추억" | 추억 모달, 카테고리 9종 그리드 |
| 03-2 | 카테고리 선택 | 감정 태그/연도/메모 입력 화면 전환 |
| 03-3 | "바꾸기" 탭 | 카테고리 그리드로 복귀 |
| 03-4 | 감정·연도 미선택 저장 | 저장 성공(전부 선택값) |
| 03-5 | 메모 입력 후 이어두기 | 목록/상세 타임라인에 반영 |
| 03-6 | 홈 재진입 | 히어로 카드 추억 줄에 최신 추억 반영 가능 |

## TC-04 재연락 미션 (핵심)
| # | 단계 | 기대 결과 |
|---|---|---|
| 04-1 | 홈/상세 "용기 내보기" | 미션 진입, 상단 진행칩(워밍업/용기/초안/기록) |
| 04-2 | 워밍업 "보냈어요, 다음으로" | 부스터 단계, 워밍업 칩 ✓ |
| 04-3 | 부스터 카드 3장 스와이프 | 넛지 2장(31→53%, 반가워함) + 추억 카드 1장, "이제 써볼게요" |
| 04-4 | 초안 단계 | 템플릿 3종, **추억 소환** 기본 선택, 추억 문구 자동 삽입 |
| 04-5 | 템플릿 전환 | 안부/추억/솔직 문구 각각 바뀜 |
| 04-6 | 초안 직접 편집 | 텍스트 수정 반영 |
| 04-7 | "복사하고 카카오톡 열기" | 클립보드 복사, 결과 단계로 이동. **(실기기)** 24h 팔로업 알림 예약 |
| 04-8 | "😊 답장이 왔어요" | "다시 이어졌어요" + **상태 전환 질문**(멀어진→이어진) 노출 |
| 04-9 | "네, 이어진 관계로" | 상태 CONNECTED로 변경, 마지막 연락일 갱신 |
| 04-10 | "⏳ 아직 답이 없어요" | 격려 화면, 미션은 열린 채 유지(홈 미션 카드 잔존) |
| 04-11 | "😔 아직 못 보냈어요" | 죄책감 없는 격려 화면 |

## TC-05 안전 불변식 (백엔드 규칙)
| # | 단계 | 기대 결과 |
|---|---|---|
| 05-1 | 보호 모드 관계 상세 진입 | "용기 내보기" 버튼 없음, 보호 안내 노출 |
| 05-2 | (API) 보호 관계 미션 생성 시도 | HTTP **409** 거부 (`POST /api/people/{id}/missions`) |
| 05-3 | 안전 우려 관계는 홈 추천에서 제외 | 히어로 후보에 미노출 |

## TC-06 관계 상세 & 리마인더
| # | 단계 | 기대 결과 |
|---|---|---|
| 06-1 | 사람 카드 탭 | 상세: 프로필/상태/추억 타임라인 |
| 06-2 | 연락 리마인더 칩(없음/2주/한 달/석 달) | 선택 시 서버 저장(contactCycleDays) |
| 06-3 | **(실기기)** 주기 선택 | 알림 권한 요청 → 예약 |
| 06-4 | 상세에서 "+ 추억 남기기" | 추억 모달로 이동 |

## TC-07 연락처 불러오기 (실기기 전용)
| # | 단계 | 기대 결과 |
|---|---|---|
| 07-1 | 등록 1단계 "연락처에서 고르기" | 시스템 피커 오픈(권한 팝업 없음) |
| 07-2 | 연락처 1명 선택 | 이름 필드에 자동 입력 |
| 07-3 | 웹에서 확인 | 버튼 자체가 **숨겨짐**(정상) |
