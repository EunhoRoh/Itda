# 08. 화면 설계

> 작성일: 2026-07-20
> 시각 목업: [ui-mockup.html](assets/ui-mockup.html) (아티팩트로도 공유) · 원칙: 한 화면 = 한 가지 행동

## 디자인 방향 (트렌드 반영)

잇다는 생산성 앱이 아니라 **감정을 다루는 앱**이다. 벤치마크는 명상·웰니스 앱(Calm, Headspace, 마보)의 "차분한 감성" + Duolingo의 "여정형 프로그램 UI".

1. **웜 미니멀리즘**: 크림/웜그레이 배경, 낮은 채도의 포인트 컬러, 넉넉한 여백. 갈등을 다루는 앱이 차가우면 안 된다
2. **큰 타이포 + 한 화면 한 질문**: 폼을 쪼개서 대화하듯 진행 (요즘 온보딩 표준). 글자가 UI의 주인공
3. **카드 기반 정보 구조**: 사람·추억·미션 전부 카드. 복잡한 리스트 대신 만지고 싶은 단위
4. **여정(Journey) 시각화**: 재연락 미션·용서 프로그램을 단계 지도로 보여줌 — 진행감이 리텐션을 만든다
5. **마이크로 인터랙션**: 미션 완료 시 실이 이어지는 애니메이션(브랜드 모티프), 햅틱. 과한 게이미피케이션(포인트·랭킹)은 배제 — 사람 관계를 점수화하면 천박해진다
6. **다크모드 기본 지원**, 시스템 폰트 스케일 대응(중장년 타깃 → 큰 글씨 모드 중요)

**브랜드 모티프: 실(thread).** "잇다"의 시각 언어 — 사람 카드 사이를 잇는 실, 미션 완료 시 매듭이 지어지는 연출. 컬러: 살구/코랄 계열(따뜻함) + 딥그린(안정) 조합.

## 정보 구조 (IA)

```
탭 3개 (하단):
├── 홈          — 오늘의 제안(다시 잇고 싶은 사람 1명) + 진행 중 미션
├── 내 사람들    — 관계 카드 목록 (상태 필터: 이어진/멀어진/틀어진)
└── 나          — 내 여정 기록, 설정, 구독

모달 플로우 (탭 밖 전체화면):
├── 사람 등록 (연락처 선택 or 직접 입력 → 관계 유형 → 상태 → 안전 스크리닝)
├── 추억 기록 (카테고리 → 감정 태그 → 시기 → 사진/메모)
├── 재연락 미션 (워밍업 → 용기 부스터 → 초안 → 복사&이동 → 결과)
└── 화해 브리지 (개별 AI 상담 → 준비도 → 합동방)   ※ Phase 2
```

## 핵심 화면 정의

### S1. 홈
- 상단 인사: "오늘, 한 사람만 이어볼까요?"
- **히어로 카드 1장**: 다시 잇고 싶은 사람 추천 (사진/이니셜, "마지막 연락 3년 전", 추억 1줄) + CTA `용기 내보기`
- 아래: 진행 중 미션 카드(단계 표시), 다가오는 기념일
- 설계 의도: 목록을 보여주지 않는다. **한 명에게 집중** — 선택 마비 방지

### S2. 내 사람들
- 상태 필터 칩: 전체 / 🔵 이어진 / 🟡 멀어진 / 🔴 틀어진
- 관계 카드: 이름(별칭), 관계 유형, 마지막 연락, 추억 수, 상태 색 실 장식
- FAB `+ 사람 잇기`

### S3. 사람 등록 (한 화면 한 질문, 4스텝)
1. 누구인가요? — `연락처에서 불러오기`(선택 피커) or 직접 입력(별칭 가능)
2. 어떤 사이인가요? — 관계 유형 칩 선택
3. 지금 어떤 상태인가요? — 🔵🟡🔴 3택 (카피: "잘 지내요 / 멀어졌어요 / 마음이 상했어요")
4. 안전 확인 — 위협·폭력 경험 1문항 (예 → 재연결 기능 차단 + 안내)

### S4. 관계 상세
- 상단: 프로필 + 상태 실 그래픽 + `용기 내보기` CTA
- 추억 타임라인 (카테고리 아이콘 카드, 연도순)
- `+ 추억 남기기`, 연락 주기 리마인더 설정

### S5. 추억 기록 (전부 탭 선택형)
- 카테고리 그리드(9칸: 여행/학창시절/같이 먹던 것/웃었던 일/도와준 일/이룬 것/일상/선물/직접입력)
- 감정 태그 칩 → 연도 슬라이더 → 사진·한줄메모(선택) → 완료 시 실 매듭 애니메이션

### S6. 재연락 미션 (여정형, 3단계 지도 상단 고정)
- **6a 워밍업**: "먼저 편한 사람에게 몸풀기 안부를" — 완료 체크
- **6b 용기 부스터**: 풀스크린 카드 스와이프 3장 — 연구 넛지 2장(31→53%, 상대는 더 반가워한다) + 내 추억 1장 ("이 기억을 아는 사람은 세상에 둘뿐이에요")
- **6c 초안 작성**: 템플릿 3종 탭(안부형/추억 소환형/솔직형), 추억 자동 삽입, `AI로 다듬기`(선택) → 큰 버튼 **`복사하고 카카오톡 열기`** (전송 버튼 없음 — 보내는 건 사용자의 것)
- **6d 결과 기록**(24h 후 푸시 랜딩): 😊 답장 왔어요 / ⏳ 아직요 / 😔 못 보냈어요 → "못 보냈어요"는 격려 화면 (죄책감 카피 금지)

### S7. 화해 브리지 — 개별 AI 상담 (Phase 2)
- 채팅 UI. 상단에 여정 단계칩: `마음 정리 → 준비 확인 → 함께 대화`
- 시작 시 구조화 입력 2문항(서운했던 점 / 오해라고 생각하는 점) — 채팅으로 이어짐
- AI 말풍선은 시스템 톤(중립 색), "상담사가 아닌 조력자" 고지 배너 1회
- 산출물 화면: "함께 대화에서 하고 싶은 말" 카드 (편집 가능, 공유 동의 체크)

### S8. 화해 브리지 — 합동방 (Phase 2)
- 3자 채팅: A(우측)·B(좌측)·AI(중앙 정렬, 구분 배경)
- 상단: 진행 단계 표시(이야기 듣기 → 서로 확인 → 오해 정리 → 마음 전하기 → 마무리)
- AI 발언에 `잠시 쉬어가기` 버튼 상시 노출 (냉각은 언제든 사용자가 먼저 누를 수 있음)
- 종료 화면: 오늘 확인한 것 1가지 + 각자 해볼 것 1가지 요약 카드

## UI 생성 협업 방법 (사용자 질문에 대한 답)

Claude로 UI를 생성해 전달하는 방식 — **가능하고 권장**. 실전 순서:
1. 이 문서 + [ui-mockup.html](assets/ui-mockup.html)(정적 목업)으로 방향 합의 ← 지금 단계
2. 목업 확정 후 RN 컴포넌트로 변환 (NativeWind/StyleSheet) — 목업 HTML을 그대로 스펙으로 사용
3. 디자인 토큰(색/타이포/간격)을 `mobile/src/theme.ts`로 코드화해 일관성 유지
Figma가 필요해지면(외부 디자이너 협업 시) Figma MCP로 목업을 Figma 파일로 밀어넣는 것도 가능.
