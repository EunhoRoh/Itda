## Phase 0 — 기획 마무리 (지금)

- [x] 리서치 (심리학 근거, 시장, 데이터 수집 현실성, 오픈소스)

- [ ] 화면 설계 (와이어프레임) — 핵심 5화면: 홈 / 사람 등록 / 추억 기록 / 재연락 미션 / 결과 기록
- [ ] 잔여 조사: 카카오 메시지 API 초대장 용도 가능 여부, B2B 경쟁 조사

## Phase 1 — MVP 개발 (8~10주 목표)

**루프 하나를 끝까지: 사람 등록 → 추억 → 워밍업 → 용기 부스터 → 초안 복사 → 결과 기록**

| 주차 | 백엔드 (Spring Boot) | 모바일 (RN/Expo) |
|---|---|---|
| 1-2 | 프로젝트 셋업, 인증(카카오+JWT), person/relationship/memory 도메인 | Expo 셋업, 온보딩·로그인, 홈 뼈대 |
| 3-4 | 미션(재연락 플로우) 도메인, 리마인더 스케줄러(Redis) | 사람 등록(연락처 선택 불러오기), 추억 기록 UI |
| 5-6 | 푸시 발송(FCM/APNs), 결과 기록 API, 넛지 콘텐츠 API | 재연락 미션 3단계 플로우, 메시지 템플릿+복사 |
| 7-8 | 통계(North Star 집계), 안전 스크리닝 분기 | 결과 기록, 리마인더 설정, 마감 다듬기 |
| 9-10 | 버퍼, 부하·보안 점검 | 내부 테스트(TestFlight/내부 트랙), 스토어 심사 대응 |

스토어 심사 리스크 대비: 연락처 권한 용도 문구, 민감정보 처리방침, Apple 로그인 포함.

## Phase 2 — 회복 엔진 (MVP+1)

- REACH 5단계 용서 여정 (4주 프로그램, 저널링 + 일일 10분 세션)
- 사과 작성 코스 (6요소 블록 에디터)
- 화해 초대 링크 (받는 쪽 무료)
- 구독 결제 (인앱 결제) 도입
- **검증 게이트**: Phase 1의 North Star(재연결 성사 수)와 리텐션이 기준 미달이면, 기능 추가 대신 루프 개선으로 회귀

## Phase 3 — B2B 파일럿 (Itda for Teams)

- 조직/워크스페이스 도메인, 익명 집계 리포트
- 직장 버전 콘텐츠 팩 (NVC 대화 준비, 직장 톤 사과 가이드)
- 1:1 화해 브리지
- 소규모 회사 1~2곳 무료 파일럿 → 사례 확보

## 마일스톤 지표

| 시점 | 지표 | 목표 |
